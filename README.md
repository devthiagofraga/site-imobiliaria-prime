# 🏢 Prime Imóveis - Website Institucional Responsivo

Website institucional desenvolvido para uma corretora de imóveis fictícia, focado em alta performance, boas práticas de SEO, acessibilidade e design responsivo.

## 🚀 Tecnologias Utilizadas
* **HTML5 Semântico:** Estruturação acessível com uso de tags como `<header>`, `<nav>`, `<section>` e `<footer>`.
* **CSS3 Moderno:** Utilização de Flexbox e CSS Grid para layout flexível e responsivo.
* **Mobile First Concept:** Adaptações de layout otimizadas para dispositivos móveis e desktops.

## 💡 Recursos
* Navegação com rolagem suave (*smooth scroll*).
* Seção de cartões (*cards*) de imóveis em destaque.
* Design responsivo que se ajusta a diferentes tamanhos de tela.
